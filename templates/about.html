🎯 Project Overview

The Smart Log Monitoring and Intrusion Detection System is an AI-powered cybersecurity platform that automatically analyzes system log files to detect malicious activities and security threats. This system uses Machine Learning techniques such as TF-IDF (Term Frequency-Inverse Document Frequency) and Logistic Regression to classify log data into Normal or Intrusion categories. The system improves security monitoring by increasing detection accuracy, reducing manual analysis, and providing faster and more reliable intrusion detection.

✅ Objectives

  • Automatically monitor and analyze system log files
  • Detect malicious activities using AI algorithms
  • Classify logs as Intrusion or Normal using TF-IDF and Logistic Regression
  • Store prediction results securely in MySQL database
  • Provide real-time dashboard for monitoring intrusion activities
  • Reduce manual effort and improve security efficiency

🛠️ Technologies Used

  • Python Flask (Backend Framework)
  • Machine Learning – TF-IDF Vectorizer and Logistic Regression
  • Scikit-learn (ML Model Training and Prediction)
  • MySQL Database (Data Storage)
  • HTML, Tailwind CSS (Frontend Design)
  • JavaScript (User Interaction)

📦 System Modules

  • User Authentication Module
  • Upload Log File Module
  • Machine Learning Intrusion Detection Module
  • Normal Log Monitoring Module
  • Results and Prediction Storage Module
  • Dashboard Visualization Module
